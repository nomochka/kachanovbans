# KachBans — инструкция для модераторов и администраторов

Эта инструкция описывает защищённый вход, выдачу наказаний, прикрепление доказательств и управление ботами KachBans.

## 1. Первый вход сотрудника

Защищённый вход обязателен для всех сотрудников

При первом входе выполните действия строго по порядку:

1. Откройте личные сообщения Discord-бота и отправьте `/link`.
2. Бот выдаст одноразовый шестизначный код. Код действует 10 минут.
3. В Minecraft введите `/ds add <код>`.
4. Перезайдите на сервер, если бот или сервер попросит это сделать.
5. В личных сообщениях Discord проверьте ник и IP входа, затем нажмите **Подтвердить**.
6. После успешной 2FA в Minecraft введите `/access <ключ>`.

Ключ зависит от вашей группы или назначается персонально. Не отправляйте его в чаты, не показывайте на трансляции и не передавайте другим сотрудникам.

На каждый этап даётся 60 секунд. Пока вход не подтверждён, сотрудник не может двигаться, взаимодействовать с миром, писать в чат или выполнять обычные команды. После истечения времени сервер отключит игрока.

## 2. 2FA и доверенная сессия

При запросе входа Discord-бот показывает:

- ник игрока;
- IP-адрес входа;
- время, до которого нужно ответить;
- кнопки **Подтвердить** и **Отклонить**.

Нажимайте **Подтвердить** только после собственного входа на сервер. Если вход выполняли не вы или IP незнаком, нажмите **Отклонить** и сообщите старшему составу. Отклонение аннулирует запрос и отключает подозрительное подключение.

После выхода доверие для того же IP сохраняется 60 минут. При входе с другого IP подтверждение требуется заново.

Команды управления 2FA:

| Команда | Назначение |
| --- | --- |
| `/2fa status` | Показать состояние 2FA и привязки |
| `/2fa on` | Включить добровольную 2FA для обычного игрока |
| `/2fa off` | Выключить добровольную 2FA для обычного игрока |

Для сотрудников из защищаемых групп 2FA обязательна и отключить её нельзя. Повторно отправлять `/2fa on` не требуется.

## 3. Выдача наказания в Minecraft

### Блокировки и муты

| Команда | Назначение |
| --- | --- |
| `/ban <ник> [причина] [-s]` | Бессрочная блокировка |
| `/tempban <ник> <срок> [причина] [-s]` | Временная блокировка |
| `/unban <ник> [причина]` | Снять блокировку |
| `/mute <ник> [причина] [-s]` | Бессрочный мут |
| `/tempmute <ник> <срок> [причина] [-s]` | Временный мут |
| `/unmute <ник> [причина]` | Снять мут |

### Блокировки по IP

| Команда | Назначение |
| --- | --- |
| `/ipban <ник или IP> [причина] [-s]` | Бессрочная блокировка IP |
| `/tempipban <ник или IP> <срок> [причина] [-s]` | Временная блокировка IP |
| `/ipunban <ник или IP> [причина]` | Снять блокировку IP |

При IP-бане KachBans блокирует сам адрес и известные ники, связанные с ним. В публичных сообщениях IP скрывается.

Примеры срока: `10s`, `30m`, `2h`, `1d`, `1h30m`. Флаг `-s` скрывает общее игровое объявление, но само наказание и служебная запись сохраняются.

Если на игроке уже есть совместимое наказание, KachBans предложит кнопки для замены или добавления. Используйте кнопки в чате; служебную команду подтверждения вручную вводить не нужно.

## 4. Доказательства до применения наказания

Наказание, выданное модератором, не применяется сразу. Порядок работы:

1. Введите команду наказания в Minecraft.
2. KachBans создаст ожидающую заявку и напишет вам в личные сообщения Discord.
3. Прикрепите к сообщению бота скриншот, видео или файл с доказательством.
4. После приёма доказательства бот применит наказание.
5. В канал наказаний уйдёт оформленное сообщение вместе с прикреплённым доказательством.

На отправку доказательства даётся 60 минут. Если доказательство не приложено вовремя, наказание не применяется, а старший состав получает уведомление.

Для команд, выполненных из консоли сервера или через RCON, доказательства не требуются.

Не отправляйте боту посторонние файлы. Убедитесь, что доказательство относится именно к указанному игроку и нарушению.

## 5. Проверка наказаний и истории

| Команда | Назначение |
| --- | --- |
| `/banlist [страница]` | Список активных блокировок |
| `/mutelist [страница]` | Список активных мутов |
| `/history <ник> [страница]` | Полная история наказаний игрока |
| `/iphistory <ник> [страница]` | История известных IP игрока |
| `/dupeip <ник> [страница]` | Аккаунты с совпадающим IP |
| `/checkban <ник>` | Проверить активную блокировку |
| `/checkmute <ник>` | Проверить активный мут |

В `/history` наведите курсор на запись: во всплывающей подсказке отображаются тип наказания, модератор, причина, время выдачи, срок и окончание.

Если Essentials также зарегистрировал `/ban`, `/mute` и похожие команды, KachBans должен перехватывать обычные варианты команд. При неожиданном поведении сообщите тех. администратору и приложите скриншот с точной командой.

## 6. Команды через Discord-бота

Команды наказаний принимает бот, но выполнять их могут только Discord-аккаунты из разрешённого списка, которым суперовнер назначил роль.

Доступные команды:

- `/ban`, `/unban`, `/mute`, `/unmute`;
- `/tempban`, `/tempmute`;
- `/role` — назначение роли внешнему администратору, доступно только суперовнеру;
- `/setpunishments` — назначить текущий канал каналом наказаний;
- `/setbotlogs` — назначить текущий канал полным журналом действий бота.

БУДЕТ ДОПОЛНЯТЬСЯ

Привязка Minecraft-аккаунта и ответы на 2FA доступны всем. Ограниченный список Discord ID относится именно к удалённым командам управления наказаниями и настройке каналов.

Чтобы назначить Discord-канал:

1. Откройте нужный канал на Discord-сервере.
2. Выполните в нём `/setpunishments` или `/setbotlogs`.
3. Убедитесь, что бот ответил об успешном сохранении.

Эти команды доступны только админам бота. Боту нужны права видеть канал, отправлять сообщения, прикреплять файлы и встраивать ссылки.

## 7. Работа через Telegram

Telegram-бот работает только в чате администрации.

- `/setpunishments` назначает текущий чат или тему каналом наказаний.
- `/setbotlogs` назначает текущий чат или тему журналом всех действий бота.

Эти настройки меняет Telegram-суперовнер. Права на удалённые команды также назначаются суперовнером.

## 8. Команды администратора сервера

| Команда | Назначение |
| --- | --- |
| `/kachanovbans reload` | Перезагрузить конфигурацию KachBans |
| `/kachanovbans migrate essentials` | Импортировать баны и муты Essentials |

Миграция доступна только оператору сервера или консоли. Она импортирует поддерживаемые записи Essentials, пропускает истёкшие наказания и дубликаты. Перед миграцией сделайте резервную копию данных обоих плагинов и после выполнения проверьте `/banlist`, `/mutelist` и несколько записей `/history`.

## 9. Если вход или команда не работают

Проверьте по порядку:

1. Discord-аккаунт привязан через код, полученный в ЛС бота.
2. Запрос 2FA подтверждён именно для вашего ника и текущего IP.
3. После 2FA введён действующий ключ вашей группы.
4. В LuckPerms назначена правильная основная группа из списка защищаемых групп.
5. Бот находится онлайн и может отправлять вам личные сообщения.
6. У вас есть право LuckPerms на нужную команду KachBans.

Не публикуйте в обращении токены ботов, ключ доступа или полный конфиг. Для диагностики достаточно ника, времени ошибки, введённой команды, скриншота ответа и — при необходимости — ID Discord без секретов.

## Краткая памятка

1. Привязка: `/link` в ЛС Discord-бота → `/ds add <код>` в Minecraft.
2. Вход: проверить ник и IP → **Подтвердить** → `/access <ключ>`.
3. Наказание: ввести команду → дождаться ЛС бота → прикрепить доказательство.
4. Не подтверждать чужой вход и никому не передавать ключ.
5. После наказания проверить публикацию и при необходимости запись в `/history`.
